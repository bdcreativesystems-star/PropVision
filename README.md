# PropVision - Real Estate Listing Aggregator & Dashboard

PropVision is a full-stack Python project that aggregates real estate listings, stores them in a database, and presents them in a clean, interactive dashboard.

## Features
- Web scraping of property listings
- Database storage using SQLite
- Dynamic Flask dashboard with Bootstrap
- Filters by price and square footage
- Interactive charts with Chart.js
- Analytics cards for total listings, average price, and price per square foot

## Tech Stack
- Python (Scraper, Analytics)
- Flask (Web App)
- SQLite (Database)
- BeautifulSoup (Web Scraping)
- Bootstrap & Chart.js (Frontend/UI & Charts)
